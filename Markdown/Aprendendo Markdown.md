# SINTAXE MARKDOWN #

- Os cabeçalhos são criados usando o símbolo de **cerquilha** (#).
Dependendo do número de cerquiilhas, você definirá o nível do cabeçalho, de h1 a h6.

 - Para estilizar o texto em **negrito**, utilizamos dois asteriscos (**) ou dois _sublinhados_ (__).

- Para *itálico*, usamos um asterisco (*) ou um sublinhado (_).

- Listas não ordenadas são criadas usando o hífen (-), asteriscos (*) ou sinais de mais (+).

- Listas ordenadas utilizam números seguidos de um ponto.
1. Primeiro item
2. Segundo item
3. Terceiro item
4. Quarto item
    * 4.1. Subitem do quarto item
    * 4.2. Outro subitem do quarto item

- Para criar links, utilizamos colchetes para o texto do link e parênteses para a URL.
[Ramiro Lobo](https://www.ramirolobo.com)

- As imagens são inseridas de forma semelhante aos links, mas precedidas de um ponto de exclamação (!).
![Imagem de exemplo](https://www.exemplo.com/imagem.jpg)

- Para adicionar uma linha horizontal, utilizamos três ou mais hífens (---), asteriscos (***) ou sublinhados (___).
---

- Para destacar código em linha, usamos crases (`) ao redor do texto.`
    `código em linha`

- Para blocos de código, utilizamos três crases (```) antes e depois do código.

```using System;
class Program
{
    static void Main()
    {
        Console.WriteLine("Olá, Mundo!");
    }
}
```
